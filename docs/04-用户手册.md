# ROS 节点通信系统 — 用户手册

> 面向使用者：如何编译、运行、编写自己的节点以及排查常见问题。
> 版本：v1.0　日期：2026-11-16

## 1. 这个程序做什么？

它用 C++ 模拟 ROS 的发布-订阅通信：发布者（Publisher）把消息发到某个话题（Topic），订阅者（Subscriber）从该话题被动接收。支持多个发布者/订阅者、异步连续发布、完整生命周期与清晰的异常处理。

## 2. 快速开始

### 2.1 编译
1. 用 Visual Studio 2022 打开项目根目录的 `RosSimulation.sln`。
2. 选择配置 `Debug | x64`，按 `Ctrl+Shift+B` 生成解决方案。
3. 解决方案包含两个项目：
   - **RosSimulation**：演示程序
   - **RosSimulationTests**：结构化测试

### 2.2 运行演示
将 `RosSimulation` 设为启动项目，按 `F5`。控制台会依次输出：
- 各发布者/订阅者的初始化日志
- 消息发布与接收日志（含消息内容与时间戳）
- 5 类非法输入的异常日志（程序不崩溃）
- 全局关闭日志

同时会在工作目录生成 `ros_simulation.log`，保存同样的日志。

### 2.3 运行测试
将 `RosSimulationTests` 设为启动项目，按 `F5`。每个用例输出 `[PASS]` 或 `[FAIL]`，末尾给出汇总：

```
----------------------------------------
Total: 13  Passed: 13  Failed: 0
```

## 3. 编写自己的节点

只需四步：创建节点 → 初始化 → 发布/接收 → 全局关闭。示例：

```cpp
#include "Publisher.h"
#include "Subscriber.h"
#include "ROS.h"
#include "Logger.h"

int main() {
    // 可选：把日志同时写入文件
    Logger::instance().enableFileLog("my_ros.log");

    Publisher temperaturePublisher("temperature_publisher", "sensor/temperature");
    Subscriber display("display_node", "sensor/temperature");

    temperaturePublisher.init();   // 向 ROS 核心注册
    display.init();

    temperaturePublisher.publish("temperature=26.5C");  // 异步发布，立即返回
    temperaturePublisher.publish("temperature=27.0C");

    ROS::instance().shutdownAll(); // 回收线程并关闭所有节点
    return 0;
}
```

编译时应把 `include/` 加入「附加包含目录」，并把 `src/` 下除 `main.cpp` 以外的 `.cpp` 加入项目（或直接在现有 VS 项目中替换 `src/main.cpp`）。

## 4. API 速查

| 类 | 主要接口 | 说明 |
|---|---|---|
| `Node` | `name()`, `isInitialized()`, `init()`, `shutdown()` | 所有节点的抽象基类，`init`/`shutdown` 由子类实现 |
| `Publisher` | `topic()`, `init()`, `shutdown()`, `publish(data)` | 向指定话题发布字符串消息 |
| `Subscriber` | `topic()`, `init()`, `shutdown()`, `receive(message)` | 被动接收消息；`receive` 为虚函数可重写 |
| `Message` | `content()`, `timestamp()` | 只读访问消息内容与时间（`YYYY-MM-DD HH:MM:SS`） |
| `ROS` | `instance()`, `registerPublisher()`, `registerSubscriber()`, `publish()`, `shutdownAll()`, `publisherCount()`, `subscriberCount()`, `nodeCount()` | 核心单例，管理映射与生命周期 |
| `Logger` | `instance()`, `log()`, `enableFileLog()`, `disableFileLog()` | 分级日志；也可用宏 `LOG_INFO/LOG_WARN/LOG_ERROR` |

## 5. 异常说明

| 触发条件 | 异常类型 |
|---|---|
| 节点名为空 | `NodeException` |
| 节点名称重复注册 | `NodeException` |
| 话题名为空 | `TopicException` |
| 向无订阅者的话题发布 | `TopicException` |
| 消息内容为空 | `MessageException` |
| 未初始化就发布 | `NodeException` |

所有异常都继承自 `ROSException`（再继承自 `std::exception`），可用 `catch (const ROSException& e)` 统一捕获，`e.what()` 给出具体原因。程序不会因这些非法操作崩溃。

## 6. 注意事项

1. **先初始化再发布**：发布前必须调用 `init()`，否则抛 `NodeException`。
2. **关闭顺序**：退出前调用 `ROS::instance().shutdownAll()`，它会等待异步派发线程结束并关闭所有节点；不要在节点对象销毁后才调用。
3. **节点名唯一**：同名节点只能注册一次。
4. **日志级别**：`INFO` 为常规流程，`WARN` 为重复初始化等可恢复情况，`ERROR` 为已捕获的异常。
5. **VS 版本**：项目文件使用 v143 工具集（VS2022）；若使用 VS2019，请把两个 `.vcxproj` 中的 `<PlatformToolset>` 改为 `v142`。
